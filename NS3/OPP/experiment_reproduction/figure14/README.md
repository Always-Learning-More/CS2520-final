# Figure 14

Run from `NS3/OPP/` (the directory that contains `simulation/` and
`experiment_reproduction/`):

```bash
python3 experiment_reproduction/figure14/run_figure14.py
```

The runner executes Figure 14.

Results are written to:

```text
experiment_reproduction/figure14/results/
```

Default output files:

```text
experiment_reproduction/figure14/results/Figure14(a)_results.csv
experiment_reproduction/figure14/results/Figure14(b)_results.csv
```
