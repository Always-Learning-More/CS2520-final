# Figure 6

Run from `NS3/OPP/` (the directory that contains `simulation/` and
`experiment_reproduction/`):

```bash
python3 experiment_reproduction/figure6/run_figure6.py
```

The runner executes Figure 6.

Results are written to:

```text
experiment_reproduction/figure6/results/
```

Default output files:

```text
Figure6_results.csv
```
